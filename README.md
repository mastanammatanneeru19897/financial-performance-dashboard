# 📊 Financial Performance Dashboard

## 📌 Project Overview
This project delivers an interactive Power BI dashboard designed for corporate finance teams to streamline decision-making. It integrates data from SQL databases and Excel files to monitor revenue, track departmental expenses, and perform comprehensive Budget vs. Actual variance analysis.

## 🛠️ Tech Stack Used
- **SQL Server:** For data extraction, cleaning, and calculating financial metrics.
- **MS Excel:** Used for maintaining annual budget targets.
- **Power BI:** For ETL (Power Query), Data Modeling, and interactive dashboard creation.

## 💡 Key Insights Provided
- **Profitability Tracking:** Real-time monitoring of Gross Profit and Net Profit Margins.
- **Variance Analysis:** Identification of departments exceeding their allocated budgets.
- **Expense Control:** A clear breakdown of major operational expenses (OpEx) to identify cost-cutting opportunities.

## 🗂️ How to Use This Repository
1. Open the `financial_queries.sql` file to view the SQL data-prep logic.
2. Download the `Financial_Performance_Dashboard.pbix` file to explore the interactive report.
